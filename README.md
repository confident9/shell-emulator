# Эмулятор оболочки UNIX (Вариант 30)

Проект представляет собой эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом на базе `tkinter` и поддержкой виртуальной файловой системы (VFS) на основе JSON.

## Реализация по этапам задания

1. **Этап 1 (REPL)**: Графический интерфейс на Tkinter, заголовок окна `Эмулятор - [username@hostname]`, парсинг аргументов с поддержкой кавычек (`shlex`), команды-заглушки `ls`, `cd`, команда `exit`.
2. **Этап 2 (Конфигурация)**: Поддержка параметров `--vfs` и `--script`, отладочный вывод параметров при запуске, выполнение стартовых скриптов с поддержкой комментариев (`#`).
3. **Этап 3 (VFS)**: Виртуальная файловая система в формате JSON (двоичные данные в base64), работа в памяти, команда `vfs-save`, вывод `motd` при старте, скрипты тестирования для разных вариантов VFS.
4. **Этап 4 (Основные команды)**: Реализация логики `ls` и `cd`, команды `date` и `cal`.
5. **Этап 5 (Дополнительные команды)**: Реализация команд `chmod` и `touch` с модификацией VFS только в памяти.

## Команды

- `ls [путь]` — просмотр содержимого каталога
- `cd [путь]` — смена текущей директории
- `date` — вывод даты и времени
- `cal [год] [месяц год]` — вывод календаря
- `chmod <права> <путь>` — изменение прав доступа
- `touch <путь>` — создание файла / обновление времени
- `vfs-save <путь>` — сохранение VFS в JSON-файл
- `exit` — выход из эмулятора

## Запуск

Запуск эмулятора:
```bash
python3 main.py --vfs vfs_samples/full.json
```

Запуск со стартовым скриптом:
```bash
python3 main.py --vfs vfs_samples/full.json --script scripts/test_commands.sh
```

Запуск в консольном режиме:
```bash
python3 main.py --cli --vfs vfs_samples/full.json
```

## Тестирование

Запуск модульных тестов:
```bash
python3 -m unittest discover tests
```

Запуск скриптов ОС:
```bash
bash scripts/run_test_config.sh
bash scripts/run_test_minimal.sh
bash scripts/run_test_full.sh
bash scripts/run_test_commands.sh
bash scripts/run_test_extra.sh
```
