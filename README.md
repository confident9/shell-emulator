Учебный проект по дисциплине **«Конфигурационное управление»**.  
Проект представляет собой полнофункциональный эмулятор командной строки UNIX-подобной операционной системы с графическим интерфейсом (GUI) и виртуальной файловой системой (VFS), функционирующей исключительно в оперативной памяти.

## ✨ Особенности проекта

- 💻 **Графический интерфейс пользователя (GUI)**: реализован в ретро-терминальном стиле (цветовая палитра `#1e1e1e` / `#00ff00`), динамический заголовок окна `Эмулятор - [username@hostname]`.
- 🧠 **Виртуальная файловая система в памяти**: дерево каталогов и файлов хранится в JSON с `base64`-кодированием бинарного содержимого; операции модификации происходят без обращений к физическому диску.
- 💬 **Стартовые скрипты и диалог**: поддержка комментариев `#`, последовательное выполнение команд с отображением ввода/вывода (имитация интерактивной работы).
- 🛡️ **Надёжный синтаксический анализ**: разбор командной строки с поддержкой одинарных, двойных и вложенных кавычек через библиотеку `shlex`.
- 🧪 **Комплексное тестирование**: 50 модульных unit-тестов и набор автоматизированных сценариев тестирования ОС.

## 🏛️ Архитектура системы

Взаимодействие компонентов эмулятора построено по модульному принципу:

```text
[ Пользовательский ввод / Стартовый скрипт ]
                      │
                      ▼
             ┌─────────────────┐
             │   src/parser    │  (shlex: токенизация, обработка кавычек)
             └────────┬────────┘
                      │  (cmd, [args])
                      ▼
             ┌─────────────────┐
             │  src/emulator   │  (Ядро эмулятора: REPL, prompt, маршрутизация)
             └────────┬────────┘
                      │
         ┌────────────┴────────────┐
         ▼                         ▼
┌──────────────────┐      ┌──────────────────┐
│   src/commands   │      │     src/vfs      │
│  ls, cd, date,   │◄────►│  Дерево VFSNode  │
│  cal, touch...   │      │  (JSON + base64) │
└──────────────────┘      └──────────────────┘
```

## 📌 Реализация этапов задания

| Этап | Название | Реализованные требования |
|---|---|---|
| **Этап 1** | **REPL** | Графический интерфейс на `tkinter`, заголовок `Эмулятор - [username@hostname]`, парсинг аргументов в кавычках (`shlex.split`), команды-заглушки `ls`, `cd`, команда завершения `exit`. |
| **Этап 2** | **Конфигурация** | Аргументы командной строки `--vfs` и `--script`, отладочный вывод всех параметров при запуске, выполнение скриптов с комментариями `#` и имитацией диалога, тестовый скрипт ОС `run_test_config.sh`. |
| **Этап 3** | **VFS** | Модель файловой системы в памяти, JSON-формат, кодирование двоичных данных в `base64`, сохранение на диск по `vfs-save`, вывод приветствия из файла `motd`, 3 тестовых образца VFS (минимальный, несколько файлов, 3+ уровней) и соответствующие скрипты ОС. |
| **Этап 4** | **Основные команды** | Полноценная логика команд `ls` и `cd` (абсолютные и относительные пути, `..`, `.`, обновление prompt), новые команды `date` (дата и время) и `cal` (календарь месяца/года), тестовые скрипты. |
| **Этап 5** | **Дополнительные команды** | Команда `chmod` (изменение прав доступа узла в памяти), команда `touch` (создание файла или обновление времени модификации), тестовые скрипты для проверки модификации VFS и обработки ошибок. |

## 📖 Справочник команд

| Команда | Синтаксис | Пример | Описание |
|---|---|---|---|
| `ls` | `ls [путь]` | `ls home/user` | Вывод содержимого директории или информации о файле |
| `cd` | `cd [путь]` | `cd ../documents` | Смена текущего каталога (поддерживает `.`, `..`, `/`) |
| `date` | `date` | `date` | Вывод текущей даты и системного времени UNIX |
| `cal` | `cal [год] [месяц год]` | `cal 2026` / `cal 10 2026` | Отображение календаря текущего месяца или указанного года |
| `chmod` | `chmod <права> <путь>` | `chmod 755 motd` | Изменение прав доступа узла VFS в оперативной памяти |
| `touch` | `touch <путь>` | `touch notes.txt` | Создание пустого файла или обновление времени изменения |
| `vfs-save` | `vfs-save <файл.json>` | `vfs-save backup.json` | Экспорт текущего состояния VFS на физический диск |
| `exit` | `exit` | `exit` | Завершение работы эмулятора оболочки |

### Примеры работы в интерактивном режиме:


## 🗄️ Виртуальная файловая система (VFS)

Виртуальная файловая система представляет собой N-арное дерево узлов `VFSNode`.  
Фрагмент структуры JSON-источника:

```json
{
  "name": "/",
  "is_dir": true,
  "permissions": "rwxr-xr-x",
  "children": [
    {
      "name": "motd",
      "is_dir": false,
      "permissions": "rw-r--r--",
      "content": "0JTQvtCx0YDQviDQv9C+0LbQsNC70L7QstCw0YLRjCE="
    },
    {
      "name": "home",
      "is_dir": true,
      "permissions": "rwxr-xr-x",
      "children": [ ... ]
    }
  ]
}
```

- **Двоичные данные**: содержимое файлов кодируется алгоритмом `base64`.
- **Изоляция**: все операции (`touch`, `chmod`, создание файлов) изменяют только граф объектов в оперативной памяти и не затрагивают физическую файловую систему до вызова команды `vfs-save`.

## 🚀 Установка и запуск

### Системные требования
- Python версии **3.8** или выше
- Стандартная библиотека Python (`tkinter`, `shlex`, `json`, `base64`, `unittest`)

### Варианты запуска

```bash
# 1. Запуск десктопного GUI с полной VFS (Вариант №30)
python3 main.py --vfs vfs_samples/full.json

# 2. Запуск со стартовым скриптом автоматического тестирования
python3 main.py --vfs vfs_samples/full.json --script scripts/test_commands.sh

# 3. Запуск в консольном режиме REPL (CLI)
python3 main.py --cli --vfs vfs_samples/full.json

# 4. Запуск через универсальный скрипт запуска
chmod +x run.sh
./run.sh --vfs vfs_samples/full.json
```

## 🧪 Тестирование

### Модульные тесты (Unit Tests)
Проект содержит **50 модульных тестов**, покрывающих все уровни абстракции:
- `test_parser.py`: тестирование кавычек, пробелов, экранирования и синтаксических ошибок.
- `test_vfs.py`: тестирование разрешения путей, обхода дерева, чтения, записи и экспорта JSON.
- `test_commands.py`: проверка логики выполнения всех команд и обработки некорректных аргументов.
- `test_emulator.py`: тестирование жизненного цикла REPL, приглашения `prompt` и выполнения скриптов.

Запуск всех модульных тестов:
```bash
python3 -m unittest discover -s tests -v
# или
./run.sh test
```

### Скрипты тестирования реальной ОС
Для каждого этапа подготовлен сценарий тестирования в среде ОС:
```bash
bash scripts/run_test_config.sh    # Проверка всех конфигураций параметров
bash scripts/run_test_minimal.sh   # Проверка минимальной VFS и motd
bash scripts/run_test_several.sh   # Проверка VFS с несколькими файлами
bash scripts/run_test_full.sh      # Проверка глубокой VFS (3+ уровня)
bash scripts/run_test_commands.sh  # Проверка основных команд
bash scripts/run_test_extra.sh     # Проверка команд chmod и touch

# Запуск всех проверочных сценариев одной командой:
./run.sh all
```
